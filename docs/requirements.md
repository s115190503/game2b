# 需求與驗收

## 功能需求

- FR-01：遊戲有開始、故事、第一關、第二關、成果畫面。
- FR-02：第一關要求玩家從四個物品中選兩個需要品，答對才取得第一把 KEY。
- FR-03：第二關要求玩家調整每週儲蓄值，正確答案為 10 元，答對才取得第二把 KEY。
- FR-04：每關顯示 0/100 至 100/100 得分，結束顯示 0/200 至 200/200 與學習成果。
- FR-05：滑鼠、觸控與鍵盤可操作；重要資訊不依賴聲音。

## 非功能需求

- NFR-01：Godot Web 匯出可在現代瀏覽器載入。
- NFR-02：介面採高對比、清楚文字與低認知負荷排版。
- NFR-03：不使用後端、不要求密鑰，適合 GitHub Pages/Netlify。

## 驗收情境

1. 開始遊戲 → 選早餐與雨傘 → 顯示第一關 100 分並進入第二關。
2. 第二關設定 10 元 → 顯示第二關 100 分與兩把 KEY。
3. 成果頁顯示總分 200/200、兩關分數及三項學習成果。
